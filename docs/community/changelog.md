# Changelog

Release history is maintained automatically from conventional commits:

- **[CHANGELOG.md on GitHub](https://github.com/infinidysk/infinidysk/blob/main/CHANGELOG.md)**
- **[GitHub Releases](https://github.com/infinidysk/infinidysk/releases)** — downloadable tags and notes

Breaking upgrades (including irreversible database migrations) are called out under Breaking Changes; releases with routine additive migrations note it in the release announcement. Back up `/config` before upgrading across any version that includes a migration — [Backups and upgrades](../guides/backups-upgrades.md).
